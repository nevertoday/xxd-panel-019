> تعرّف أولاً · اختزل بقصد · كوّن بالكتابة

XXD Panel 019 هي مهارة لتوليد الصور مخصّصة لـ Codex والوكلاء المتوافقين معه. تترجم الموضوع والوضعية والاتجاه والنسبة والعلاقات التي لا يمكن فصلها إلى إيضاح مسطّح ريترو-حداثي يمكن التعرّف إليه. وهي ليست تتبعاً متجهياً للصورة، ولا ذريعة لمحو المصدر تحت هندسة عامة.

الاختزال يزيل الضوضاء، لا الهوية.

## لماذا وُجدت هذه المهارة؟

تنتهي كثير من عمليات تحويل الصور إلى إيضاحات مسطّحة إلى مجموعة أدوات بصرية واحدة: يتحول الأشخاص إلى ظلال بلا ملامح، والمكان الحقيقي إلى شمس وطريق، وتأتي الألوان من قالب، وتغدو الكتابة حشواً زخرفياً. تبدو الصورة مصمّمة، لكنها لم تعد تخص الصورة الأصلية.

يشترط 019 بقاء ثلاثة مؤشرات هوية خاصة بالمصدر على الأقل في كل مشهد محوّل: المحيط الخارجي أو الوضعية أو الاتجاه أو النسبة أو التراكب أو الشكل السلبي أو المسافة بين الموضوعات. يمكن أن تكون الهندسة جريئة، لكن ينبغي للمشاهد أن يدرك أي مشهد تعيد روايته.

```text
الصورة الأصلية ← تحديد الموضوع والعلاقة ← تثبيت مؤشرات الهوية ← استخراج 3–5 ألوان ← إعادة البناء ← تنضيد النص ← الفحص
```

## العقد البصري لـ 019

- **التعرّف أولاً:** حافظ على الموضوع والعلاقة قبل السعي إلى التوتر الغرافيكي.
- **ثلاثة مؤشرات هوية على الأقل:** يعمل المحيط والوضعية والنسبة والاتجاه والتراكب والشكل السلبي معاً.
- **ثلاثة إلى خمسة ألوان من المصدر:** تأتي اللوحة من الصورة، لا من مثال أو قالب.
- **الشكل الموجب والسالب وتباين المقياس:** تصنع المساحات الكبيرة والسطوح الحادة والمنحنيات المقتضبة والفراغ مسار النظر.
- **طابع طباعي متقشّف:** يدعم التنقيط الخفيف وملمس الورق وانزياح التسجيل التسلسل المسطّح بدلاً من محاكاة 3D لامع.
- **طباعة تحريرية:** يشارك العنوان والنص الدقيق في الهندسة والوزن البصري والإيقاع المكاني.

## أربعة مخرجات قابلة للجمع

يمكن اختيار نمط واحد أو عدة أنماط بـ `1` أو `1+3` أو `1,2,4` أو `الكل`؛ وينتج «الكل» سبعة ملفات PNG مستقلة لكل مصدر. بعد اختيار النمط وقبل التوليد، تُحسم نسبة لوحة الناتج كاملة: `3:4` الخاصة بالتوجيه الأصلي، أو نسبة المصدر باختيار صريح، أو نسبة شائعة، أو نسبة／بكسلات مخصصة. لا تُطبّق أبعاد المصدر ضمنياً.

| النمط | قاعدة اللوحة | الناتج |
| --- | --- | --- |
| `top-bottom` | لوحة نهائية أكدها المستخدم | توليد كامل واحد: المصدر عالي الوفاء في الأعلى وتصميم 019 في الأسفل، نحو 50/50 |
| `left-right` | لوحة نهائية أكدها المستخدم | توليد كامل واحد: المصدر عالي الوفاء يساراً وتصميم 019 يميناً، نحو 50/50 |
| `design-only` | لوحة نهائية أكدها المستخدم | يملأ تصميم 019 اللوحة ولا تظهر صورة المصدر |
| `wallpaper-pack` | تأكيد مستقل لكل جهاز | ملفات PNG منفصلة للهاتف وiPad والحاسوب وساعة الأطفال |

تستخدم الأنماط الثنائية المصدر كمدخل تحرير／مرجع عالي الوفاء، وتولّد التكوين النهائي مباشرة بتوجيه الأسلوب الكامل كي تتماسك الصورة والتصميم واللون والضوء والكتابة والمعنى. ولا يُستخدم التركيب الحتمي إلا بعد فشل إعادة محاولة محددة للوحة الكاملة، أو عند طلب حفظ المصدر بكسلاً ببكسل، أو عجز مسار التوليد عن تحقيق اللوحة، أو للحاجة إلى معايرة نهائية بلا فقد.

يمكن أن تكون الخلفيات مترابطة أو مستقلة. تعتمد المترابطة عملاً مرجعياً واحداً لـ iPad ثم تعيد تكوين كل جهاز من الأصل والمرجع نفسه. أما المستقلة فيرجع كل جهاز فيها إلى الأصل وحده. ولا يقص أي منهما ناتج جهاز آخر ولا يسلسل المشتقات.

## يجب أن ينتمي النص إلى الصورة

قبل التوليد، اختر نصاً تلقائياً أو نصاً مخصّصاً أو نتيجة بلا كتابة، وحدّد اللغة أو المنطقة في الخيارين الأولين. لا يلجأ النص التلقائي إلى كلمات عامة مثل «ذكرى» أو «حلم» أو «رحلة». بل يقرأ الواقعة المرئية والتوتر العلاقي والمعنى الضمني المدعوم، ثم يجد عنواناً يجعل المشاهد يرى الصورة مرة أخرى.

يجب أن يجتاز العنوان اختبار تبديل الصورة. إن كان صالحاً بالقوة نفسها لصورة لا علاقة لها، فهو لا ينتمي إلى هذه الصورة. وعلى النص الدقيق أن يوسّع النواة الدلالية نفسها، لا أن يملأ التكوين بأرقام تسلسلية أو ملصقات أرشيفية عشوائية.

يبقى نص المستخدم النهائي كما هو. أما الاتجاه أو المسودة القابلة للتحرير فتُعاد صياغتها فقط بعد تثبيت الجمهور والهدف والكلمات الإلزامية والنبرة والمعنى.

أولوية اللغة:

```text
السوق أو الجمهور المستهدف ← لغة الناتج المطلوبة ← لغة التوجيه؛ وإذا لم يُذكر شيء، يُسأل المستخدم قبل التوليد
```

تستخدم النسخة العربية العربية الفصحى المعاصرة ما لم يطلب المستخدم تنويعاً إقليمياً. وتحافظ على اتصال الحروف، واتجاه القراءة من اليمين إلى اليسار، وعلامات الترقيم العربية، وكسر السطور وفق المعنى، والتعامل المقصود مع النص اللاتيني والأرقام. لا تُعكس الصورة أو اتجاه الموضوع آلياً؛ الذي يتغير هو تدفق الكتابة ومحاذاتها. ولا تستنتج المهارة الجنسية أو اللغة من المظهر، ولا تستخدم حروفاً أجنبية زائفة.

## أولوية اللوحة الكاملة وحدود الصورة النقطية

يتولى نموذج الصور إعادة البناء الجمالي للعمل النهائي كله، وتستخدم التركيبات الثنائية أيضاً توليد لوحة كاملة واحدة افتراضياً. ولا يبقى `scripts/compose_panel.py` إلا للاسترداد المشروط ومعايرة البكسلات بلا فقد والتدقيق للقراءة فقط؛ فلا يعمل مسبقاً ولا يحكم على النجاح الجمالي.

كل التسليمات ملفات PNG نقطية، وينشئ كل استدعاء مهمة جديدة تحت `~/Desktop/xxd/`. ولا يكشف مسار الصور المضبوط سوى حالة منزوعة التفاصيل، من دون المزوّد أو نقطة الاتصال أو بيانات الاعتماد أو الرؤوس أو التوجيهات أو الاستجابات أو معلومات الحساب. ولا تصلح SVG أو HTML أو Canvas أو الرسوم البرمجية بديلاً للعمل النهائي.

## الحدود والثقة

- الصورة الحالية هي مصدر المحتوى الوحيد للمهمة؛ لا تُستعار مدخلات أخرى أو نتائج سابقة أو أمثلة مرفقة.
- يفتح كل استدعاء مجلد مهمة جديداً، حتى مع الصورة والمعلمات نفسها.
- النواتج ملفات PNG نقطية، وليست SVG أو HTML أو Canvas أو رسوماً برمجية بديلة.
- لا يعرض جسر الصور سوى حالة منزوعة التفاصيل الحساسة، ولا يطبع المزوّد أو نقطة الاتصال أو الرؤوس أو بيانات الاعتماد أو التوجيهات أو نص استجابة الخادم.
- يعيد كل نمط عادي مختار ملفاً واحداً، ويضيف اختيار `wallpaper-pack` أربع خلفيات مستقلة. يعيد خيار «الكل» سبعة ملفات PNG لكل مصدر داخل أربعة مجلدات أنماط متجاورة، ولا ينشئ لوحة تجميع أو عرضاً عاماً.

يتطلب التركيب المحلي Python 3 وPillow. ويستخدم جسر الصور الآمن `tomllib` في Python 3.11 أو أحدث. أما التوليد فيحتاج إلى قدرة نقطية مدمجة في الوكيل المضيف أو مسار نقطي متوافق ومُعدّ مسبقاً.
