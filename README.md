# XXD Panel 019

**把每张照片转成双联、单画面，或手机／iPad／电脑／儿童手表四端壁纸套装**

</div>

## 关于本项目

这是一个适用于读取 `skills/` 目录的 agent Skill。每张源照片独立生成完成作品：

- 四种模式可选：上下双联、左右双联、纯设计版、四端壁纸套装。
- 双联模式严格 50/50；纯设计版只显示设计后的插画，不显示原照片。
- 可给任意画布比例或精确像素尺寸；精确像素优先级最高。
- 双联中可见的摄影只做克制调色与必要的无缝环境延展。
- 变化画框把同一主体与关系转译成可辨认的复古现代主义平面插画。
- 使用 3–5 个源照片颜色，不引入无来源配色。
- 文案默认开启，支持无文案、用户成稿、创作方向、自动创作四级优先级。
- 普通模式一张源图对应一个 PNG；壁纸套装对应四个独立 PNG，不生成拼贴、九宫格或系列总览。

## 使用方法

克隆这个独立项目，再把目录链接到所使用 agent 的 skills 目录：

```bash
git clone https://github.com/nevertoday/xxd-panel-019.git
mkdir -p ~/.claude/skills
ln -s "$(pwd)/xxd-panel-019" ~/.claude/skills/xxd-panel-019
```

Codex 使用独立 skills 目录时，将链接目标改为 `~/.codex/skills/xxd-panel-019`。

```text
$xxd-panel-019
请把这些照片逐张制作成 019 风格海报。
```

未指定模式时，skill 会先询问：

> 请选择模式（回复序号即可）：
>
> 1. 上下双联（默认 3:4）
> 2. 左右双联（默认 3:2）
> 3. 纯设计版（默认 3:4，不显示原照片）
> 4. 四端壁纸套装
>    手机＋iPad＋电脑＋儿童手表，默认有文字
>
> 可同时附带尺寸；壁纸套装可按设备分别给分辨率。

选择四端壁纸套装且没有说明图片关系时，skill 会继续询问：

> 请选择壁纸关系（回复序号即可）：
>
> 1. 连贯套装（推荐）
>    先生成 iPad 定调图；其他三张参考原照片＋定调图分别重构
> 2. 四张独立
>    每张只参考原照片，构图变化更自由

连贯套装不是把一张图改成四个尺寸：iPad 定调图先通过验收，其他设备每次都同时参考原照片和同一张定调图，并针对自己的画布重新构图。不会使用 iPad → 手机 → 电脑 → 手表的串联垫图，避免误差逐张累积。定调图就是四张成品之一，不额外生成第五张。

也可以在首条请求中直接指定，例如“左右双联，2560×1440”，此时不会重复询问。

成品默认保存到 `~/Desktop/xxd-panel-019/`，并按“原图名＋模式”建立独立任务子文件夹。普通模式的文件夹只放一张最终 PNG；四端壁纸套装的文件夹放手机、iPad、电脑和手表四张最终 PNG。重复任务在文件夹名后自动增加 `-2`、`-3`，不覆盖旧结果，也不会把不同原图的成品混在一起。

再次调用始终创建新的生成任务，即使原图、模式和尺寸完全相同，也会重新生成到新的编号子文件夹。旧成品不会被自动当作参考图或本次结果；只有用户明确要求继续、编辑、复核或复用某个旧文件时才会读取它。

## 模式、尺寸与精确合成

模式和尺寸是两个独立选项。尺寸优先级为：**精确像素 > 明确比例或用途 > 模式默认值**。

| 模式 | 默认画布 | 成品结构 |
| :--- | :---: | :--- |
| 上下双联 `top-bottom` | 3:4 | 原照片在上、变化插画在下，严格等高 |
| 左右双联 `left-right` | 3:2 | 原照片在左、变化插画在右，严格等宽 |
| 纯设计版 `design-only` | 3:4 | 设计后的插画铺满画布，原照片仅作为生成依据，不出现在成品中 |
| 四端壁纸套装 `wallpaper-pack` | 四种设备尺寸 | 手机、iPad、电脑、手表各一张，默认有文字 |

精确上下双联要求总高度为偶数，精确左右双联要求总宽度为偶数；skill 不会静默修改奇数尺寸。纯设计版接受任意正整数像素尺寸，并直接按最终尺寸生成。

壁纸套装默认输出手机 1440×3200、iPad 2048×2732、电脑 3840×2160、儿童手表 1024×1024。可以按设备分别覆盖尺寸。壁纸关系可选“连贯套装”或“四张独立”；两者都会针对各自宽高比重新构图并保留系统 UI 安全区，不会从一张主图机械裁切。

双联模式分别准备摄影画框和变化画框，再用脚本按像素拼接：

```bash
scripts/compose_panel.py --plan --layout top-bottom
# → 画布 1440x1920，每半幅 1440x960

scripts/compose_panel.py --layout left-right --size 2560x1440 \
  --source photo.png --design illustration.png \
  --out ~/Desktop/xxd-panel-019/IMG_4821-lr.png

scripts/compose_panel.py --layout design-only --size 2048x2048 \
  --design illustration.png \
  --out ~/Desktop/xxd-panel-019/IMG_4821-design.png
```

旧参数 `--top` / `--bottom` 仍可作为 `--source` / `--design` 的兼容别名。

检查已有成品的接缝：

```bash
scripts/compose_panel.py --audit poster.png --layout top-bottom
scripts/compose_panel.py --audit poster-lr.png --layout left-right
scripts/compose_panel.py --audit artwork.png --layout design-only --size 2048x2048
```

## 文案执行逻辑

每张照片在生成前分别锁定文案包：

1. 用户明确不要文案：完全无字，也不生成装饰性伪文字。
2. 用户提供完整成稿：逐字保留，不改写、不翻译。
3. 用户提供创作方向：按该方向生成一个确定版本。
4. 用户没有提供：所有模式都根据照片自动生成主标题和 2–4 组微型文字，语言按目标受众解析。

自动文案会依次读取表层事实、主体之间的关系张力，以及这些事实共同暗示的潜台词，再用精准命名、反差、低调陈述、双重含义或轻微反转提炼标题。标题必须通过“换图测试”：换到一张无关照片仍然成立，就必须重写。目标是克制、准确的“会心一击”，不强行玩梗，也不虚构原图无法证明的故事。

完整成稿逐字保留，并按语义词组处理重音、断行、字号与位置；创作方向或可编辑草稿则先理解受众、传播目的、必须保留的词、语气和潜台词，再在允许范围内专业精炼。只有歧义会实质改变意思时才追问。

文案语言优先看目标受众，而不是下指令时用了什么语言：目标市场／受众地区 > 指定成品语言 > 文案方向语言 > 当前请求语言。用中文要求“日本版”会转创为自然日语，“韩国受众”使用自然韩语，“英国版”使用英式英语。日语遵守汉字／假名比例、日文标点和禁则断行；韩语遵守空格与谚文字块；英式英语使用英国拼写、词汇、日期习惯和克制语气。不会根据人物长相或场景猜国籍，也不会用伪外文制造国际感。

锁定内容连同不显示的 `COPY INTENT` 语义说明一起传入变化画框生成请求，避免模型临时改字、添加无关文字，或让视觉排版偏离文案原意。

## 核心原则

1. 普通模式一张照片对应一张成品；壁纸套装严格对应四张独立文件，多图仍逐张处理。
2. 双联严格 50/50；源图隐藏模式不出现原照片或接缝；壁纸四端分别重新构图，连贯模式以“原照片＋同一定调图”扇出而不串联。
3. 双联中的摄影保持真实；变化画框必须可追溯到同一主体和关系。
4. 先保证辨识度，再用几何色块、正负形、尺度和层级建立图形张力。
5. 最终验收在合成、保存和模式审计之后进行；硬错误只重做有问题的画框一次。

## 与 XXD Panel 016 的关系

019 与 016 共用同一套执行骨架：先选四种模式之一、再定尺寸、逐图隔离、双联中的原片保护、Codex 位图生图、变化画框独立生成、壁纸安全区、脚本收口、视觉验收。壁纸套装统一输出四张、默认有文字，并提供“连贯套装 / 四张独立”关系选择；两种关系都逐设备重新构图，禁止用 SVG 或程序化绘图代替生图。

两者只保留必要的风格差异：019 的变化画框使用「可辨认主体 × 复古现代主义平面插画 × 3–5 色」，文案在目标语言中保持现代主义编辑层级；016 的变化画框使用「极小锚点 × 单一运动场 × Riso/丝网印刷 × 2–3 色」，文案在目标语言中保持极短、克制的实验艺术书气质。
